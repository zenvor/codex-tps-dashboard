统计口径 / 数据限制

后台整轮耗时直接采用任务完成事件中的持续时间，包含模型请求、工具执行、最终回答输出、请求准备和客户端编排。桌面端完成后显示的“工作了 X 分 X 秒”固定在最终回答开始时，因此通常更短；JSONL 没有保存桌面端所用的精确结束时间，本页面不会估算或伪造桌面端口径。

请求外耗时 = 后台整轮耗时 − 模型请求占用，主要包括工具实际执行、客户端编排、下一次请求准备和重试；等待模型响应属于模型请求耗时，不在请求外耗时中。整轮 TPS = 全部输出 Token / 后台整轮耗时。请求 TPS = 全部输出 Token / 模型请求占用时间，包含请求等待、推理和网络时间。正文 TPS ≈ 只描述正文输出项开始后的估算速度。模型汇总会受任务难度、工具数量和上下文影响。
